# Steam on Android

Android-проект с интерфейсом для Steam и игровым экраном с настраиваемым touch-контролем.

## Что уже есть
- вход в Steam через официальный web login;
- загрузка официального `SteamSetup.exe`;
- игровой экран в landscape;
- экранные W/A/S/D, Space, Shift, Ctrl, E, Esc;
- отдельные ЛКМ/ПКМ справа;
- размер и прозрачность контролов;
- перетаскивание кнопок по экрану;
- GitHub Actions для сборки debug APK.

## Важное ограничение
Сам по себе Android не запускает Windows `.exe`. Чтобы реально устанавливать и запускать купленные Windows-игры локально, нужен ARM/x86 compatibility runtime (например, Wine + Box64/Box86 или другой совместимый runtime). В репозитории намеренно не распространяются Steam-бинарники или чужие Windows-игры.

Поэтому текущая версия — рабочая основа/launcher и UI управления, а не полноценный аналог Winlator. Реальная совместимость с большим каталогом игр потребует интеграции runtime, DXVK/VKD3D, контейнеров и графических драйверов.

## APK
После push в `main` workflow **Build APK** собирает `app-debug.apk` и публикует его как GitHub Actions artifact.
