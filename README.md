# Steam on Android 🎮

Flutter-проект для Android с интерфейсом Steam и настраиваемым экранным управлением.

## Сейчас реализовано

- стабильная Flutter-основа, которую собирает GitHub Actions;
- вход через официальный Steam Web Login в системном браузере;
- каталог тестовых Steam-игр с прямыми страницами Steam;
- игровой экран в landscape-ориентации после генерации Android-проекта;
- WASD, Space, E, Esc и отдельные ЛКМ/ПКМ;
- настройка размера и прозрачности контролов;
- режим редактирования положения элементов.

## GitHub Actions

Workflow `.github/workflows/build-apk.yml` автоматически:

1. устанавливает стабильный Flutter;
2. генерирует Android-проект командой `flutter create`;
3. устанавливает зависимости;
4. запускает `flutter analyze`;
5. собирает release APK;
6. загружает APK как artifact `steam-on-android-release`.

## Важное ограничение

Android не может напрямую запускать Windows `.exe`. Для локального запуска Windows-версий купленных игр нужен полноценный compatibility runtime (Wine + Box64/Box86 или аналог), графический переводчик DXVK/VKD3D и интеграция Steam-клиента.

Текущий репозиторий **не притворяется готовым эмулятором Windows**: UI и управление подготовлены так, чтобы следующим этапом подключить runtime без переписывания интерфейса. Проприетарные бинарники Steam и файлы игр в репозиторий не включаются.

## Цель следующего этапа

Сделать цепочку `Steam login → библиотека → установка → контейнер → запуск → touch/мышь/клавиатура`, добавив профили управления для разных игр и список совместимости.
